How it works

From soil sensor to farmer's phone.

Five stages carry a single soil moisture reading all the way to a plain-language irrigation instruction — usually within the same day.

01

Field data acquisition

Soil moisture, temperature and humidity sensors deployed across geofenced plots collect readings continuously, sent over low-power IoT gateways alongside satellite imagery and farmer-submitted plot data.

Sensor networksEdge devicesSatellite imagery
02

Data transmission and integration

Sensor readings, weather data, soil reports and farmer records are ingested through APIs into a unified cloud data platform, kept in sync with the existing plot digitisation system.

Cloud infrastructureAPIsUnified data platform
03

AI analytics and predictive modelling

Cleaned, feature-engineered data feeds the eleven prediction models — irrigation timing, water stress, fertigation, pump scheduling and yield — running as an inference layer over the data platform.

Machine learningOptimisation models
04

Decision support and generative advisory

A recommendation engine combines model outputs with business rules, then a language model rewrites the result into a short, plain-language advisory in the farmer's preferred language.

Recommendation engineLLM-based advisoryMultilingual output
05

Dashboard, alerts and continuous learning

The advisory reaches the farmer through web and mobile dashboards, with alerts for stress and irrigation timing. Feedback from the field loops back to retrain and improve the models each season.

Farmer dashboardAlertsModel retraining

Operating at scale

Built for thousands of plots, not one demo farm

Running this across 18,000–25,000 farms surfaces real constraints — the system is designed around them rather than around ideal conditions.

CONNECTIVITY

Village-level connectivity

Sensor gateways buffer and resend data through intermittent rural network coverage.

MAINTENANCE

Sensor upkeep

Calibration schedules and battery-life monitoring built into the field operations plan.

ADOPTION

Farmer trust

Human-in-the-loop review and manual override keep agronomists in the decision, not just the AI.
